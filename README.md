Комплексная веб-платформа для строительной компании, объединяющая интернет-магазин, систему B2B-заказов и мощный внутренний модуль серверной веб-аналитики с эвристическим скорингом лидов.

---

## Ключевые возможности (Features)

### Электронная коммерция и Каталог
- **EAV-архитектура каталога:** Гибкая система атрибутов, позволяющая назначать разные наборы характеристик строительным материалам.
- **Гостевые корзины:** Хранение корзины и списка "Избранного" в сессиях без обязательной регистрации.
- **Сохранение историчности цен (Price Snapshot):** При оформлении заказа цена копируется в заявку, защищая исторические отчеты от будущих изменений прайс-листов.
- **Мягкое удаление (Soft Delete):** Защита старых заказов. При снятии товара с производства он блокируется визуально, но не удаляется физически (`is_active=False`).
- **Генератор ЧПУ (Slug Generator):** Автоматическая транслитерация и рекурсивное разрешение коллизий URL-адресов при совпадении названий.

### Аналитика и Rule-based ML Скоринг
- **Server-side трекинг:** Независимая система мониторинга через Middleware, не блокируемая AdBlock. Выдача криптографических UUID, хеширование IP-адресов, фильтрация системных запросов.
- **Lead Scoring (Оценка заявок):** Встроенный алгоритм оценки (0-100 баллов). Учитывает RFM-метрики, домен почты (B2B/B2C), поведение на сайте (просмотры, клики) и автоматически присваивает заявкам статус `HOT/WARM/COLD`.
- **ETL-процессы:** Фоновая агрегация сотен тысяч сырых логов (`PageVisit`, `UserEvent`) в сжатые дневные метрики (Management-скрипт) для снижения нагрузки на сервер (HighLoad Optimization).
- **Admin Dashboard:** Интерактивная аналитическая панель с воронкой конверсий и графиками (Chart.js), динамически адаптирующаяся под Dark/Light темы.

### Пользователи и Авторизация
- **Бесшовная склейка сессий (Session Merging):** Уникальный алгоритм. При регистрации гостя система находит его UUID-cookie и через транзакционные SQL-запросы (`.update()`) переносит его гостевую корзину, избранное и историю просмотров на официальный профиль.
- **B2B Мультипрофили:** Поддержка ролевой модели. Пользователь может иметь несколько профилей (физическое лицо / компания) и переключаться между ними.
- **Защита от Open Redirect:** Жесткая валидация URL-адресов при авторизации и добавлении в корзину.

### Интерфейс (UI/UX)
- **Mobile-First Design:** Адаптивная верстка на Tailwind CSS. Выдвижные меню, "прилипающий" нижний бар действий (Bottom Action Bar) для смартфонов.
- **Оптимизация рендеринга:** Решение проблемы N+1 запросов с помощью `select_related` и `prefetch_related` (снижение количества запросов с ~100 до 2 на страницу).
- **Защита от состояний гонки (Race Condition):** Использование `F-expressions` уровня БД при обновлении количества товаров в корзине.
- **Интерактивные элементы:** JS-карусели товаров (`scroll-snap`), умный поиск с плашками сброса, глобальные Flash Messages.

## 🛠 Технологический стек
* **Backend:** Python 3.10+, Django 5.x
* **Database:** SQLite (готов к миграции на PostgreSQL)
* **Frontend:** HTML5, Tailwind CSS, JavaScript (Vanilla)
* **Libraries:** Django Unfold (Admin Theme), Chart.js, python-slugify, phonenumbers
